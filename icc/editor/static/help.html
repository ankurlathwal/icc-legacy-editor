How to use ICC Editor

An unofficial, fan-made editor for the databases of International Cricket Captain (1998), Australian Cricket Captain (1998), International Cricket Captain 2 (1999), ICC 2000, ICC 2001, ICC 2002, ICC 2005 and ICC 2006. It edits the game's own files and keeps a backup every time you save.

Getting started

  1. Close the game first. It reads the databases when you start a new game.
  2. Click Choose game folder… and pick the folder the game is installed in (for example C:\Games\ICC 2000). On Windows the folders are listed right in the editor: start from a drive or your Desktop, and folders that hold an ICC game are marked 🏏 with an Open button. You can also pick any folder that holds a copy of the database files, or paste a folder path.
  3. The editor finds the files by itself:
    • ICC 1998 and Australian Cricket Captain: database.db plus their *.fxt fixture files
    • ICC 2: database.db
    • ICC 2000 / 2001 / 2002: dataT.db (players) and DataP.db (teams), plus the *.fxt fixture files
    • ICC 2005: dataT.db and dataP.db plus the Fxt folder
    • ICC 2006: Data\dataT.db, Data\dataP.db and the Fxt folder
  4. Make your changes, press Apply changes on each page, then Save to game files (top right).

Recent folders are listed on the start screen. Open another game switches to a different game; Quit closes the editor. Both warn you first if you have changes that are not saved.

Players

  • Search by name, filter by team or nationality, and sort by batting or bowling. The list keeps its place while you edit.
  • Details tab: name, date of birth, county, national team, wages, and every ability: batting (including Test/ODI/List A ratings and form), bowling (type, arm, form, economy), fielding, role (wicketkeeper, batting role, left/right-handed), fitness, loyalty and contract length.
  • Stats tab: career batting, fielding and bowling records for each format (Test, ODI, First-class, List A…).
  • Batting: higher is better. Bowling and economy: lower is better, like a bowling average.
  • + New player creates a player who copies the abilities of a player you pick, so start from someone similar and adjust.
  • Delete player also removes them from every squad and picked XI; their place in the XI is filled automatically.
  • Changing a player's county moves them into that county's squad.

Teams

  • Change a team's name, short name and abbreviation.
  • For counties and national sides: the squad, the picked XI in batting order, the captain, wicketkeeper and opening bowlers, and club details such as year founded, kit colour and budgets.
  • Adding a player to a county squad moves them from their old county. National squads can include anyone.

Grounds & club records

  • Grounds: names, addresses and the description shown in the game.
  • Club records: each team's record book: partnerships for every wicket, highest and lowest totals, most runs and wickets in a season, best bowling and highest score. (ICC 1998 and Australian Cricket Captain have no club record books.)

Fixtures (ICC 1998, Australian Cricket Captain, ICC 2000, 2001, 2002, 2005, 2006)

  • Pick a fixture file at the top of the list. ICC 2000/2001/2002: fix1 = first season, fixX = later seasons, int1/intX = the same seasons' international fixtures only, wc = World Cup, sc* = historical scenarios. ICC 2005 and 2006 have one file per season (fix05, int05…). ICC 1998: eng98. Australian Cricket Captain: aus1998 = first season, ausX = later seasons (its seasons run from October).
  • ICC 1998 and Australian Cricket Captain name domestic sides directly, so the Fixture key only lists the international rotation slots. ICC 1998 fixtures have no venue or day/night setting (the game always uses the home side's ground). These games allow at most 30 matches on one day.
  • Change the date, competition, home and away side, venue, day/night, and the match number in a series (e.g. 2nd Test of 3). Duplicate a fixture to add similar ones quickly.
  • Venue: "Home side's ground" lets the game choose: the 1st Test of a series at the host's first ground, the 2nd at its second, and so on. Each fixture in the list shows the ground the game will use.
  • Fixture key: fixtures name their teams by numbered slot. Slots 1–9 are Championship Division 1 and 10–18 Division 2 (the National League has its own slots). Swapping two counties' slots moves them between divisions without touching any fixture.
  • "To be decided" and "Draw position" sides in cup and World Cup knockouts are filled in by the game as the competition goes on.

Saving & backups

  • Apply changes keeps an edit in the editor. Nothing is written to the game until you press Save to game files.
  • Before writing, the editor builds the files and checks them by reading them back. If anything looks wrong, it doesn't save.
  • Every save first copies each changed file to <name>.bak-<date-time> next to it. To undo a save, delete the file and rename its backup back (e.g. dataT.db.bak-20260101-120000 → dataT.db).

Playing your edits

  • Start a new career or game to see your changes. Saved games keep their own copy of the data they started with.
  • If you edited a copy of the files rather than the game folder, copy them back into the game folder (ICC 2006: databases into Data, fixtures into Fxt). Keep the original files somewhere safe.
  • Always keep dataT.db and DataP.db together as a pair from the same database.

Game limits worth knowing

  • Only Test nations can play Tests, ODIs and triangular series. The game has them built in (ICC 2000/2001/2002: the nine Test nations; ICC 2005 and 2006 add Bangladesh). Kenya, Scotland, Ireland and the other Associates can only appear in World Cup fixtures; anything else crashes when the match starts. The editor blocks such fixtures.
  • Every home side needs a ground. Most Associates have no grounds in the database, so a fixture with one of them at home needs an explicit venue. The editor flags these fixtures in the list.
  • ICC 2000 compressed releases: some copies ship their backgrounds, grounds, maps and photos packed in .ARH files that a DOS tool unpacks. That tool doesn't run on 64-bit Windows, so the game draws screens on top of each other. Unpacking the bkdps, grnds, maps, mlms and photos folders (for example with DOSBox) fixes it.

Troubleshooting

  • "Could not open": pick the folder that contains the database files (or the game folder that holds the Data folder for ICC 2006).
  • Save fails with "permission denied": Windows protects games installed under Program Files. Move the game to a folder such as C:\Games, or edit a copy and copy it back.
  • Windows: "Windows protected your PC" on first run: click More info, then Run anyway (the editor isn't signed by a registered publisher).
  • Windows: nothing appears: run runtime\Troubleshoot.bat to see the error. Log: %APPDATA%\ICC Editor\editor.log.
  • Australian Cricket Captain says it "requires your System Font Size to be set to 'Small Fonts'" on Windows 10/11: the game looks for a Windows 98 setting that no longer exists. In an administrator PowerShell run New-Item 'Registry::HKEY_CURRENT_CONFIG\Display\Settings' -Force; New-ItemProperty 'Registry::HKEY_CURRENT_CONFIG\Display\Settings' -Name DPILogicalX -Value '96' -PropertyType String -Force, then start the game again.
  • Mac: "cannot be opened because the developer cannot be verified": right-click the app, choose Open, then Open again. Log: ~/Library/Logs/ICC Editor.log.
